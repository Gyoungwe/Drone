# Research Vault

Use the bound Vault as the knowledge index for a research project.

## Workflow

1. Read the current desktop configuration and confirm the Vault is bound before writing.
2. Identify the object type: question, source, evidence, claim, decision, run, result, or method.
3. Preserve a stable identifier and source links. Keep large files in the result source of truth.
4. Write only the managed block for an existing note; keep surrounding human notes intact.
5. Record uncertainty and conflicting evidence instead of collapsing them into one conclusion.
6. Verify the resulting path and links before reporting completion.

## Completion

A Vault update is complete only when the object type, stable identifier, source links, write scope, and verification result are recorded.
