## 已落地

| 模块 | 改动 | 边界 |
|---|---|---|
| 会话恢复 | 按会话、请求、用户消息时间检查恢复条件；重复请求去重；桌面/LAN 接入受保护的只读恢复 | 不重放失败用户请求中的写操作；SDK 模拟错误恢复测试不证明真实供应商传输故障已修复 |
| 任务路由 | 已识别的只读文献复用任务收窄工具与技能；阻止无关 Shell、写入、任务授权和默认子代理 | 窄范围识别规则，不是通用任务分类器 |
| 证据账本 | 支持先读后建 run；同轮原生回执复用；reconcile 的身份核对回执可直接进入证据账本 | 原生核对无需再调用独立 verify；模型仍可能主动重复核对 |
| 论断绑定 | 论断关联具体来源、摘录、行号、关系类型、物种/方法与限制；检查读取范围、身份和摘录一致性 | 检查来源一致性，不自动判定论断科学正确或摘录足以支持结论 |
| 双库状态 | Zotero/Obsidian 分目标状态、持久化操作记录、冲突保护和恢复建议；界面显示各目标结果 | reconcile 是只读回查，不是自动补写执行器；未实现跨进程锁 |
| 阅读范围 | 最终交付附程序生成的范围说明，明确笔记复用与历史 PDF/HTML 定位的区别 | 不将笔记复核升级为本轮原文阅读 |
| 基础溯源 | `research_record_run_manifest` 记录选定文件当前哈希、宿主运行环境、命令观察引用和未验证声明 | 当前快照不是执行时输入证明；没有自动执行分析或验证 QC；本地日志不具备密码学证明能力 |

运行溯源不保存原始命令和输出，以减少凭据泄露风险；命令摘要通过 session/tool-call 引用回原始记录。失败或被拦截的工具不作为成功分析，软件版本、参数与随机种子的声明不自动视为已验证。
