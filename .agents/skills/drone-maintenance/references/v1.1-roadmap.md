## Execution rule

Open one branch/PR per package boundary, with the previous package merged and its public/install gate recorded before starting the next. Keep host fixes and plugin source commits separate when possible. Run the full root completion set at the end of each integrated step:

```sh
npm run lint && npm run typecheck && npm test && npm run build && npm run check:arch
```

Add `npm run check:remaining-gates`, `npm run check:plugin-api`, `npm run check:pi-compat -- --targets locked,latest`, `npm run check:research-suite`, and `npm run check:desktop-artifact -- --strict` wherever the changed boundary requires them. Keep Protocols.io read-only and keep the unsigned artifact policy.

## Goal is complete when

- each package has a source owner, manifest, permission/resource declaration, install smoke, Pi compatibility evidence, and public tarball verification;
- Desktop loads installed packages through the host API with no renderer-to-Pi import and no hidden host fallback;
- the refreshed suite installs cleanly and discovers all included resources;
- the plan and `docs/INDEX.md` record both repository heads, versions, evidence paths, and any remaining `BLOCKED`/`NOT_RUN` items;
- no red-line violation or unreviewed external write remains.
