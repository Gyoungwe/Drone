## 要修的问题

1. **技能列表在实机上加载不出来**（截图 04）：在"日常"空间新建会话后，技能页仍然只有仓库来源卡片，每个都是"已加载 0"，"正在检查研究技能…"一直转。需要排查：没有项目目录时技能是否根本没加载；检查任务是不是卡住了。验收方法：在空配置里新建会话后，技能页能看到按来源分组的列表。
2. **Drone 能力插件全部显示"未安装"**（截图 02、03）：pi-core、pi-knowledge、pi-research 的功能在 Desktop 里实际是可用的。如果是宿主内置的，应该显示"内置 · 已启用"，不能显示"未安装 + 安装按钮"。验收方法：已经由宿主提供的包不出现"安装"按钮，并出现在"已安装插件"里。
3. **Zotero 和 WebDAV 各出现两次**（截图 07）：连接器页里，科研连接器列表有一个 Zotero（只读引用，带开关），下面又有一个"Zotero · 本机与文献库连接"；WebDAV 在这里和"知识库设置"里各有一份。应合并成一个 Zotero 条目，开关管只读检索，抽屉里管写入方式；WebDAV 只保留在知识库设置里。
4. **知识库设置的页签重复嵌套**（截图 06）：外层是"总览与配置 / 知识库设置"，里面又嵌了一层"总览与配置 / 知识库设置 / Wiki 审核 / 索引与维护 / 相似内容检索 / 主题记忆"，而且内层看起来是灰的。只保留一层。另外，"当前 Vault"应该放在最上面，WebDAV 放在下面。
5. **Zotero 版本文案漏出占位符**（截图 08）："版本 {version} 10.0.6"。检查 `zotero-copy.ts` 里 `version` 这个键的插值写法。
6. **侧栏没有了"最近"分组**（截图 01 以后的所有截图）：设计稿和计划 §3.10 都要求侧栏有"项目、最近"两个分组，现在只剩下导航项。原报告 P1-8（"最近"列表不更新）应该是修好列表，而不是把它删掉。

7. **知识库未关联时，网络图按钮只变灰、不说明原因**：用户以为"网络图谱没了"。真实原因是开发版用 `userData-dev` 和 `~/.pi/agent-dev` 隔离配置（`main/dev-agent-dir.ts`），所以没有关联 Vault；`KnowledgeHome.tsx:145` 在 `!binding` 时直接禁用按钮。修复方法：未关联时网络图页签显示空状态，写明原因，提供"关联已有知识库 / 新建"两个按钮；开发版额外提示"这是独立配置"，并提供"使用正式版的知识库"。

### 网络图实现要点（对应 `R/components/knowledge/KnowledgeGraph.tsx` / `KnowledgeNebula.tsx`）
1. **视觉**
   - 白底，配浅点阵网格；连线默认 `#d4d4d4`，宽 1px；与选中节点相连的边加深为 `#525252`，宽 1.6px。
   - 节点颜色按类型区分：文献 `#3b6fd8`、方法 `#1f8a7a`、软件 `#c9822b`、想法 `#8a63d2`、综合页 `#3f3f46`。节点带 2px 白色描边。
   - 节点大小 = 10 + min(链接数, 7) × 3 px。
   - 链接数 ≥ 2 的节点都显示名称（节点超过 500 个时只显示中心节点），名称带 82% 不透明的白底，压在连线上也看得清；图例和缩放控件不能遮住节点。设计效果截图见 screenshots/09–11。
2. **实时刷新**
   - 订阅知识库的写入事件（新沉淀、修改、删除），走现有的知识库 IPC 事件通道，**不要轮询整个 Vault**。
   - 新节点放在它所链接节点的重心附近，**已有节点保持不动**，只做局部松弛，避免每次刷新整张图都跳动。
   - 新节点和新连线用实时绿 `#059669` 显示（和顶部实时指示点同色，避免与文献蓝混淆），节点脉冲 3 次后恢复类型色。
   - 1 秒内收到多个事件时合并成一次渲染。
   - 顶部的"实时更新 · N 秒前同步"可以点击暂停；暂停期间收到的事件先排队，恢复后一次性补上。
3. **交互**
   - 点击节点后，右侧面板显示类型、链接数、被引用数、相连笔记（可以点击跳转），以及"打开笔记 / 在对话中 @ 引用"两个按钮。
   - 按类型筛选时，不匹配的节点降到 14% 透明度，不要直接隐藏，以免丢失整体结构。
   - "实时变更"面板按时间倒序显示最近的变更，每条写明来自哪个任务、连到了几篇笔记；待审阅的修改用琥珀色标出。
4. **性能与可访问性**
   - 节点超过 500 个时改用 Canvas 或 WebGL 渲染；名称只显示中心节点。
   - 尊重系统的"减少动态效果"设置，开启时关闭脉冲和闪烁动画。
   - 节点用真正的按钮元素，带 `aria-label`（名称、类型、链接数），并能用键盘切换焦点。
5. **验收**
   - 在一个任务里沉淀一篇新笔记后，3 秒内网络图上出现这个新节点，并且其他节点不跳动。
   - 暂停后再沉淀一篇，恢复时补出现。
   - 截图与设计稿对照。
