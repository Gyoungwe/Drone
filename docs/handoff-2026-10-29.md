### 4.2 10 月 26–28 日：通用运行时与来源机制

- 同一 installed package catalog 管理 native/UI 来源；绑定安装位置、完整内容 hash、声明入口与来源代次。来源变更撤销旧调用；失效来源保留 unavailable 诊断。
- application owner、workspace/session caller、真实 SDK attachment、逐请求取消、排空及资源关闭；UI 隐藏与整包撤销分开。
- 通用 managed command、原窗口问答、input/tool/turn 链式事件、模型选择/生成/工具步、进度与错误诊断；不靠 renderer 自报身份。
- source-owned session records、受限恢复导入、显式版本化 provider；普通 JSON 不构成任务授权、执行证明或 publication 可信来源。
- SDK 最终交付/历史/导出投影、不可用 provider 私有协议和分支/取消负控；不把 raw thinking、私有签名或诊断抛进用户输出。
- 公共 Node 子路径承载通用租约和本机容器执行，领域算法继续留插件；ordinary domain worker 关闭 Node SQLite。

对应证据集中在 [runtime](pluginization/native-plugin-runtime-evidence.md)、[事件链](pluginization/native-plugin-chain-events-evidence.md)、[records](pluginization/native-plugin-session-records-evidence.md)、[恢复导入](pluginization/native-plugin-record-adoption-evidence.md)、[服务](pluginization/native-plugin-services-evidence.md)、[模型能力](pluginization/native-plugin-model-capabilities-evidence.md)、[命令](pluginization/native-plugin-managed-command-evidence.md)和[问答](pluginization/native-plugin-session-questions-evidence.md)。

## 11. 接手操作与验证方法

先核对工作树、分支、HEAD 和来源，尤其不要把临时目录中的旧 receipt 当作仍运行的进程。主整合/API打包/锁文件由主代理负责；各子代理使用各自工作树。已有未提交 child 源码不要覆盖、清理或随意打包。

宿主标准门禁：

    npm ci
    npm run lint
    npm run typecheck
    npm test
    npm run build
    npm run check:arch
    npm run check:plugin-api

插件标准门禁（本轮未发布API候选需要显式传入正确tarball）：

    DRONE_PLUGIN_API_TARBALL=<已验证的私有API绝对路径> npm run check

最终宿主取包须锁远程已推 commit/hash，不能设置 DRONE_PLUGINS_DIR 去绕过默认 fetch 的来源校验。该变量只可作明确标注的开发覆盖。

真实包 SDK 验收使用固定候选的 DRONE_PLUGIN_API_TARBALL、DRONE_KNOWLEDGE_TARBALL / DRONE_KNOWLEDGE_FULL_TARBALL、DRONE_CORE_TARBALL、DRONE_DISCOVERY_PLUGIN_TARBALL、DRONE_INQUIRY_PLUGIN_TARBALL；实际值与SHA见候选回执，不混用API2c/e41、Inquiry5908/4c5或旧Core包。

本机Docker验收使用经核对的desktop-linux本地Unix socket和已缓存python:3.12-slim；保持runner的pull=never、不联网及仅执行目录写入。两项现有opt-in变量为DRONE_DISCOVERY_REAL_CONTAINER=1、DRONE_REAL_DISCOVERY_CONTAINER=1，未启动daemon时应记录环境失败，不能改用stub声称真实通过。

分层/数据红线继续生效：renderer只经preload；SDK值import收敛session-engine；CJS preload；中英双语；JSON原子写与损坏处理；实际source/scope/lifetime；无process全局账本；不手改生成物/hash；不提交凭据、Vault/会话正文或results；错误不伪装成功。执行记录超过30条归档。
