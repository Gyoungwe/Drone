# v0.20.1

Zotero 10 本机写入与知识回执修复版。

## 变更

- **Zotero 10 本机写入**：在设置中授权「始终允许」后，可通过 Zotero 本机 API 修改个人库条目、归档集合并上传本地附件；可随时移除 Drone 保存的授权。
- **任务台账对账**：识别 Zotero 桌面个人库 ID `1`，支持按集合名称核对，并报告本机与 Web API 各自的真实失败原因。
- **回执发布**：Zotero 操作回执保持为普通回合内容，不再被错误升级为未准备知识证据的阻断。

## 验证

- main 合并后的 CI 8 项全部通过。
- PR #73、#74 的新增单元测试与真实 Zotero 10.0.3 操作记录已通过；Windows 文件权限断言按平台处理。
