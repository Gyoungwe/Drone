# Drone v0.33.0

把 Drone 收口为面向科研工作的插件化研究工作台，并完成宿主、插件合同、知识运行时和桌面产物的发布前验收。

## 研究工作台与插件

- 首页、知识库、技能与连接、主机四个工作区视口完成静态产物验收，侧栏和右栏按科研任务组织。
- UI 插件宿主支持真实启用、贡献注册、关闭、重载和重启持久化；`UI-01` 通过。
- Pi skill 通过真实 SDK 离线 provider 验收，自动调用禁用语义和手动 `/skill:` 语义均有证据；`SKILL-01` 通过。
- `@gyoungwe/plugin-api`、`pi-core`、`pi-research` 和 `research-suite` 完成构建、迁移、回滚和卸载闸门。
- MCP、只读连接器、跨实例记忆和结果红线验收通过；Protocols.io 保持只读。

## 研究资源与预览

- Nature Skills（Apache-2.0）和 Scientific Agent Skills（MIT）按固定提交、校验和回执打包。
- 增加本地 PDF.js 预览链路，保留科研文件的通用浏览器式打开能力。
- 知识与 research runtime manifest 已刷新并通过字节一致性检查。

## 发布验证

- `npm run lint`、`npm run typecheck`、`npm test`、`npm run build`、`npm run check:arch` 全部通过。
- `npm run check:desktop-artifact -- --strict`：16/16，通过四视口静态契约检查。
- 插件 API、UI/SKILL、升级 fixture、研究资源、扩展、任务 runtime、Pi 包和剩余门禁全部通过。
- 本版本按项目决定采用无证书本地构建产物策略；签名证书不是发布门槛。
