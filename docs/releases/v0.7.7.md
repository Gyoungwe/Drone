# Percho v0.7.7

## Fixed

- Windows settings, workspace, image, channel, subagent and temporary-directory tests now use native paths instead of Unix-only fixtures.
- JSON storage tests retain exact POSIX 0600 checks and verify the supported Windows read/write behavior; no failing test is skipped.
- Knowledge services stop new requests and wait for scans, pending reads and dirty batches before closing SQLite. Concurrent shutdown callers share completion, and SQLite files can be removed immediately after shutdown.
- Explicit reconciliation waits for any follow-up directory scan before reporting completion.
- Repository source line endings are enforced as LF to keep Windows and Linux lint results consistent.

## Validation

- Windows Node 24.14.1 full workspace suite: **1,250 passed** (backend 842, desktop 395, shared 13).
- Targeted knowledge lifecycle, SDK, service and upgrade UI suite: **38 passed**.
- Workspace typecheck, lint, upgrade fixtures, desktop build and isolated Electron knowledge UI smoke passed locally.
- Lint has no errors; pre-existing advisory warnings remain. Build retains third-party annotation and bundle-size warnings.
- CI now validates Windows and Linux on Node 22. The release workflow requires both validation jobs before creating a draft and building macOS, Windows and Linux assets.

## Upgrade

Use the in-app download/restart action when supported by the installed version. Older builds whose update UI is broken cannot acquire this fix merely by checking for updates: use the official installer to upgrade in place without first uninstalling, or use an already-working update entry point. Back up important data before upgrading.
