# Drone v0.7.2

Patch release for desktop command lifecycle, setup questionnaires, bounded provider probes and knowledge publication reliability.

## Fixes

- `/obsidian-review` no longer leaves a synthetic running state after opening/closing its UI.
- Prompt routing returns an explicit command/agent/queued receipt; SDK events remain the authority for running state.
- Fast completions and failed queued sends cannot be resurrected by late acknowledgements.
- Ordinary two/three-option questionnaires retain custom input; only confirmation/cancellation choices use the compact dialog.
- Provider connection tests have a 15-second deadline, abort the SDK request and disable retry; error/aborted responses cannot report success.
- Publication can perform bounded current-turn search refresh for index races while retaining strict source/binding checks.
- Setup integration tests follow the immediate model-handoff contract; HTML export assertions inspect decoded session data.
- Existing formatter errors are cleared. Root, desktop and lockfile release versions are aligned.

## Validation scope

Local release acceptance targets macOS Apple Silicon, with isolated application data, project and Vault.
Scripted loopback providers exercise real renderer input, IPC, SDK and file-writing paths; these tests do not establish real-model research quality.
The release workflow builds other platforms separately; a tag does not by itself mean their builds have succeeded.

## Distribution notes

macOS uses ad-hoc signing and is not notarized. No credentials or user Vault data are bundled.
