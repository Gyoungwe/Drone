# Drone v0.19.1

本热修复修正桌面项目账本的工作区归属，并关闭会话替换后旧扩展上下文继续运行的路径。

## 修复

- 桌面 inquiry 使用按项目隔离的 SQLite 账本，项目标识统一为工作区根目录的规范化 realpath；撤销、人工确认、任务终态、计算事件、产物查询和 IPC 列表都使用同一标识。
- v0.19.0 的 `userData/inquiry/ledger.sqlite` 作为只读旧账本登记在 StorageRegistry，未知 schema 不会被覆盖。
- 会话替换、重载和关闭会取消旧会话的 harness guard、delivery、context evaporation、任务自动续作与后台交付审稿。
- 局域网观察页移除输入、发送和权限裁决入口，设置页中英文均注明“观察页只读”。
