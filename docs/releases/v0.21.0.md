# v0.21.0

按能力路由 skill、科研工作台审计视图与并行发布流程。

## 变更

- 按能力路由 skill：研究能力拆分为 analysis、literature、writing、planning、visualization、coding；每个能力只看到自己的 skill（最多 6 个，按任务排序），加载多个能力时取并集。`capability_load` 返回每个 skill 的 SKILL.md 路径，并提示在动手前先读取（#76）。
- 知识面板：新增科研运行列表与路由图，以及运行时间线、证据缺口、复现状态的审计卡（#75）。
- 科研流程：定稿时重新校验已存的结论绑定；同一运行的更新串行执行并记录修订号，可选要求复现清单；科研子代理并发上限集中定义（#75）。
- 发布：mac / Windows / Linux 并行构建，构建产物经 workflow artifact 汇总后由单一发布任务依次上传（带重试）并发布（#77）。
