# Drone v0.30.0

## 记忆与知识库打通
- **每轮会话摘要**（#147）：每轮结束后用当前模型生成一段简短摘要（不超过 300 字），存进本机记忆库，每个会话只保留最新一条。只取你和助手的正文，跳过思考过程和工具原始输出；`<private>` 内容不送、密钥先脱敏。未信任的项目或关闭了本项目记忆时不生成。
- **沉淀到知识库**（#148）：设置 › 通用 › 本项目记忆 › 查看记录，每条可「沉淀到知识库」，写成知识库中本项目「记忆」分类的笔记（`Projects/<项目>/Memory/`），带会话、日期、涉及文件等来源，并自动链接相关笔记。原记录标为「已沉淀」，之后不再注入。知识网络星云图里记忆节点用琥珀色单独显示，并连到相关条目。
- **共享检索**（#149）：记忆不另起向量服务，直接复用知识库现有的索引和语义向量。新会话注入时先放本项目记忆，再放相关知识库条目，两者共用一个 600 token 的预算。知识库未绑定或出错时只注入记忆。
- **回答显示用到的记忆**（#150）：回答引用了记忆时，正文下方显示「使用了 N 条记忆」和对应编号（如 m:12）。
