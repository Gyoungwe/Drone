# v0.26.3

Drone 0.26.3 closes the user-facing wording of the research workflow and
keeps the task authorization constraints clear in both the desktop UI and
model-directed runtime prompts.

## Highlights

- Replaces internal process terms with concise user-facing labels while
  retaining scientific terms such as Zotero, DOI, FASTQ and Vault.
- Makes process, task, knowledge and run-detail states readable in both the
  desktop client and the LAN observation page.
- Revises authorization prompts to explain the required sequence: prepare
  inputs, submit one task plan, obtain user approval, then run commands or
  write files.
- Preserves the evidence, read-confirmation, publication-check and write-scope
  constraints, and refreshes the bundled task runtime artifacts.

## Validation

The release workflow runs repository lint, typecheck, architecture,
packaging, runtime, unit-test and production-build gates before building and
publishing the macOS and Windows artifacts.
