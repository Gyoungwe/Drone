# v0.10.1

## Fixes and improvements

- Restore the real ask_user authorization flow for task plans, additional authorization requests, stage budgets and outcome confirmations. Closing or cancelling a question never grants consent; stale task revisions and changed bindings are rejected.
- Connect task failure feedback to the live SDK flow so failures include concrete impact and next steps without breaking tool-call/result pairing.
- Improve task sidebar progress, artifact links and contextual usage refresh. Task state remains distinct from scientific validation.
- Add bounded Markdown, code, scientific-text, gzip, image and PDF previews. Script previews do not execute code, and Markdown cross-file section links preserve encoded filename characters.
- Default routine knowledge checks to nonblocking reminders, retain optional strict review and protected permission boundaries, and provide safe AI Wiki history and undo.

## Verification

The preceding functional verification passed 1006 backend, 429 desktop and 72 shared tests, workspace type checks, the Electron production build and an isolated real-Electron preview smoke test. Release CI additionally validates Linux and Windows before building macOS, Windows and Linux packages.

## Upgrade

This patch release continues the Drone 0.10.x application identity. No new migration is introduced. Existing explicit permission rules and high-risk confirmations remain in force. Saved knowledge is not scientific verification.
