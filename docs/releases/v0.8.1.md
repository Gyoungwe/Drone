# Percho v0.8.1 — 更易读的研究回答

## 改进

- **回答先给结论**：研究类回答第一屏就是建议和关键理由；需要你决定的事项紧随其后并附默认建议；run 目录、文件哈希、Wiki 链接、下载失败记录统一收进末尾的"依据与记录"一节。证据标准与发布检查没有放宽。
- **任务面板说人话**：原先显示 `stage-budget`、`reconcile-before-retry` 这类代码，现在直接说明发生了什么以及下一步怎么做（例如"本阶段的工具调用次数已用完，点'确认下一阶段预算'可继续"）。
- **预算用尽不再突然收尾**：模型会用已有信息给出当前最佳答案、说明还剩什么，并提示可从任务面板继续。

本地 Windows：lint 无错误、类型检查、backend 916 / desktop 396 / shared 13 项测试通过、应用构建通过。
