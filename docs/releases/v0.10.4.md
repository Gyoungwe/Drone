# Drone v0.10.4

本次版本把科研回答、证据链和运行中的用户决策整合成更完整的科研助手流程。

## 科研回答与证据

- 回答先给科学结论、证据等级和默认推荐，再说明支持范围、不能证明的内容和下一步证据。
- 研究设计区分原始论文、综述、知识整理和拟议方案，避免把检索或存档过程当成科学结论。
- 引用预算、原始论文证据和来源版本验证统一保留已核验的来源与交付凭证，审计信息不再因 advisory 提醒丢失。

## 知识更新与冲突

- 新旧知识冲突时保留双方证据、适用条件、来源版本和结论状态，支持比较后再升级综合结论。
- 增加 claim 绑定、冲突检测、文献收据、运行 provenance 和恢复记录，避免静默覆盖人工知识。

## 交互与任务

- `ask_user` 支持由模型根据当前问题和已观察上下文给出推荐选项、理由、置信度和依据；用户仍可改选或输入自定义答案。
- 增加模型等待、会话恢复、文献操作和知识产物状态反馈。
- 任务进度、引用和提醒在 Desktop 与 LAN 界面中使用面向用户的表达。

## 验证

- Windows 与 Linux GitHub Actions：lint、typecheck、全量测试、升级兼容性检查和生产构建均通过。
- 本地全量测试：115 个 backend 测试文件 / 1158 个测试，desktop 442 个测试，shared 80 个测试。

## 安装包

Release workflow 将构建 Windows x64、macOS Apple Silicon / Intel，以及 Linux x64 安装包。
