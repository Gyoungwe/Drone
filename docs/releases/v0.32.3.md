# Drone v0.32.3

本版本把科研连接器扩展到跨科研场景的只读资源发现，并补齐资料页的逐项开关控制。

## 科研连接器

- 新增 Zotero、Protocols.io、机构资源元数据和项目存储四个只读连接器。
- 连接器统一返回来源回执、许可/访问时间、内容哈希和失败原因。
- 科研资料页可以逐项启用或关闭连接器；设置通过 backend JsonStore 持久化，关闭后检索 fail-closed。
- 写入型适配器仍需要单独的用户授权和审计合同。

## 验证与发布状态

- PR #210 的 macOS/Windows 8 项 CI 全部通过。
- 发布采用无需证书的 unsigned 模式，安装包和更新 feed 会上传并明确标注 unsigned；macOS Gatekeeper/Windows SmartScreen 提示和安装时人工确认属于预期行为。自动更新验收覆盖 feed、资产完整性、版本切换和回滚，不承诺系统静默信任。
