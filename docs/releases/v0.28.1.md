# Drone v0.28.1

## 新增：本项目记忆（观察记忆首批，#142）
- 自动记下每次会话里改过的文件、跑过的命令和失败原因，只存规则化摘要，不存工具原始输出；`<private>…</private>` 内容不记，密钥自动脱敏。
- 新会话开始时按你的提问召回本项目以往会话中最相关的几条（中文按二字检索，不够时补最近记录），作为不超过 600 token 的参考块交给模型，并标注“可能已过时”。
- 输入框状态条显示“已载入 N 条记忆”。
- 设置 › 通用 › 本项目记忆：按项目开关、一键清空。数据只保存在本机（`<agentDir>/memory/memory.db`）。
