# Drone v0.7.8 — 通用科研任务的执行交付与安全续接

Drone 是通用科研工作助手。本次升级覆盖数据分析、代码与环境配置、实验资料处理、文件产物、写作和文献工作，不把所有任务统一改造成文献检索流程。

## 本次交付

- **执行状态不再被科研引用检查吞掉**：新增 `/task-status`；部分简短状态询问路由到宿主命令，不启动模型。实时聊天、历史记录及文件重放都显示同一个明确标注的执行检查点。
- **保留真实可观察的进展**：记录工具返回、失败、用户取消、待审核候选，以及已发起但结果未知的操作。原生写入/编辑后的受限文件回读保存大小和 SHA-256；不保存文件内容，不把文件存在说成科学正确。
- **停止不等于交付清零**：轮次限制或用户中止后保留已知结果和暂停原因。重启时结果未知的操作只提示核对，不自动重跑写入、安装或上传。
- **继续不再丢失能力入口**：“继续”“下好了”等短续接保留当前任务的工具/技能可见性；同会话恢复时重新应用当前工具排除规则。恢复的是路由可见性，不是旧权限、审批或科学证据。明确换题会重置。
- **诊断更具体**：达到轮次限制时报告实际限制和检查点，不再凭空归因于“模型弱”或“重复”。不同文件读取窗口不再被当成同一次重复读取。
- **Wiki 输入错误可修正**：`source_paths` 明确要求 1–12 个 Vault 相对 Markdown 来源笔记路径，PDF/URL 返回带字段位置的诊断；原有来源回执、证据及显式审核要求不变。
- **压缩后不鼓励重放副作用**：命令及外部工具输出淘汰后提示查询已保存日志/回执或只读状态，而不是直接重跑。
- **子代理能力预检**：可声明 `required_tools`，缺少工具时在启动模型前拒绝；明确只读 scout 没有 shell。该检查不安装工具、不扩权，也不是基于自然语言自动判断所有任务需求。

## 信任边界

执行回执不是科研结论或整体完成证明。模型自称“operational/已完成/已验证”不能绕过发布检查；宿主执行报告不转发未经检查的模型草稿。Wiki 候选仍不是已发布页面，用户取消仍不是授权。旧会话没有检查点时，不推断历史任务已经成功。

## 验证与范围

本地 Windows 验证：全量 **1292 项测试通过**（backend 883、desktop 396、shared 13）；类型检查、lint（无错误，已有建议级警告保留）、升级 fixture 验证、应用构建和隔离 Electron UI 验收通过。跨平台 CI 和发布构建由 GitHub Actions 独立执行。

新增回归覆盖通用任务续接、同会话能力恢复与当前权限排除、伪造完成标签、部分失败、分支检查点、状态命令无模型调用、实时/历史/文件重放、上下文淘汰、Wiki 输入诊断及子代理能力不匹配。隔离真实 Electron UI 验证使用临时 CSV 和宿主文件回读，未访问用户真实研究数据。

这是升级方案的 **v0.7.8 核心修复阶段**，不是完整 v0.8.0 任务调度系统：统一任务面板、完整结构化里程碑/依赖、跨任务选择与迁移、所有外部服务的结果对账、完整排队/多分支恢复仍需后续实现。检查点目前是有界历史，不保证保存全部输出；任务下一步若来自模型计划会明确标注。

安装包仅由 GitHub Actions 构建发布。自动化验证不等同于真实科研任务效果验证；本次不自动安装、不修改已有 Zotero/Obsidian 数据。
