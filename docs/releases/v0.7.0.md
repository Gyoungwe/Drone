# Percho v0.7.0

This release completes the P5–P10 knowledge and reliability roadmap and publishes the previously local 0.7.0 candidate.

## Highlights

- Opt-in hybrid lexical + semantic retrieval (off by default) with Ollama and OpenAI-compatible embedding adapters, incremental fingerprinted SQLite vector indexing, configurable minimum similarity (default 0.45), and Desktop management UI.
- Versioned project-scoped topic memory with exact/unique resume, bounded continuation context, stale-source detection, lifecycle receipts, and explicit archive controls.
- Deterministic specialist orchestration receipts plus hard-capped per-turn/session run, concurrency, queue, tool, token, and reported-cost budgets.
- Run Inspector retrieval/fallback/stop diagnostics on Desktop and LAN without exposing private chain-of-thought.
- P5–P10 regression tooling: synthetic replay, orchestration stress, production-pipeline semantic fixture, release gate, packaged-resource audit, and isolated packaged-app first-launch smoke.

## Fixes

- Permission config loader now caches by `mtime + size`, so a same-millisecond rewrite of `permissions.json` picks up deny overlays instead of stale ask rules.

## Safety and evidence boundaries

- Semantic hits, topic memory, Show Me, and child-agent reads are navigation/presentation data, not scientific evidence.
- Existing linked-Wiki-first behavior, current-version parent reads, protected human Wiki text, proposal review, and answer publication checks remain authoritative.
- Missing provider usage fields are reported as unknown rather than estimated as free or zero.
- Runtime bindings, model credentials, private Vaults, downloaded literature, sessions, browser logins, and the developer's personal skill directory are not shipped.

## New-user setup still required

Users provide their own model credentials, Vault, project trust decisions, optional search/MCP/embedding adapters, literature subscriptions/logins, and local scientific software environments. Shipping the workflow does not copy the maintainer's accounts or execution environment.

## Validation

- Local consolidated gate on 2026-09-13: lint, workspace typecheck, 1,165 tests (backend 779 + desktop 373 + shared 13), orchestration stress, production-pipeline semantic fixture, packaged-resource audit, production build, and isolated Electron UI smoke.
- A locally built Apple Silicon `Percho.app` passed isolated first-launch validation with no inherited Vault or model credentials; the packaged research-workbench resource tree passed the package/privacy audit.
- Public Release builds cover macOS (arm64/x64), Windows, and Linux (x64 AppImage/deb) via GitHub Actions; macOS remains ad-hoc signed (not notarized).
