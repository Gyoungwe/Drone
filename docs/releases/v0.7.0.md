# Percho v0.7.0 release candidate

This candidate completes the P5–P10 knowledge/reliability roadmap locally. It has not been tagged, pushed, or published as a GitHub Release by this task.

## Highlights

- Hybrid lexical + semantic retrieval is opt-in and off by default. Ollama and OpenAI-compatible embedding endpoints are supported; remote endpoints require HTTPS, explicit consent, and an environment-variable credential reference.
- The worker-owned SQLite index stores fingerprinted semantic chunks incrementally. Provider/model/chunk changes do not reuse incompatible vectors, and source changes invalidate stale vectors.
- A configurable semantic similarity threshold defaults to 0.45. FTS remains available as the lexical layer/fallback; embedding candidates never create parent evidence receipts.
- Topic memory persists bounded project-scoped summaries, entities, open questions, source hashes, runs/proposals/artifacts, and lifecycle state without copying full transcripts or private reasoning. Exact/unique topic resume is supported; ambiguous continuation returns candidates rather than silently selecting one.
- Knowledge specialists use auditable run/skip/wait/ask-user decisions with hard-capped run/concurrency/queue/tool/token/reported-cost budgets and cancellation-safe reservations.
- Run Inspector surfaces observed retrieval counts/fallbacks and operational stop reasons on Desktop and LAN.

## Safety and evidence boundaries

Semantic search, topic memory, Show Me, and child-agent reads are navigation/presentation data, not scientific evidence. Existing linked-Wiki-first behavior, current-version parent reads, protected human Wiki text, proposal review, and answer publication checks remain authoritative. Missing provider usage fields are reported as unknown rather than estimated.

## Reproducible validation

- `npm run validate:upgrade` runs repository lint, workspace typecheck/tests, P5–P10 fixture gates, production build, and isolated Electron UI smoke.
- `npm run test:upgrade` runs the deterministic orchestration stress fixture, production-pipeline semantic benchmark against a local fake HTTP embedding server, and packaged-resource audit.
- `node scripts/benchmark-semantic.mjs --live-local` optionally exercises the same persistent vector-index pipeline against a local embedding provider and only a disposable synthetic Vault.
- `node scripts/check-packaged-desktop.mjs /path/to/Percho.app` launches a built macOS app with isolated HOME/userData/agentDir/knowledgeDir and checks that no real credentials or Vault are inherited.

Synthetic replay/benchmark results are regression evidence, not a claim about general scientific retrieval accuracy. A successful local Apple Silicon build does not certify Windows, Intel macOS, notarization, or a public release.

## Local validation result

The final consolidated gate passed on 2026-09-13: lint, workspace typecheck, 1,165 tests (backend 779 + desktop 373 + shared 13), orchestration stress, production-pipeline semantic fixture, packaged-resource audit, production build, and isolated Electron UI smoke.

A locally built Apple Silicon `Percho.app` also passed isolated first-launch validation with no inherited Vault or model credentials, and its actual packaged research-workbench resource tree passed the package/privacy audit. A separate local `embeddinggemma` run exercised the persistent semantic-index path on only the synthetic benchmark Vault.

The macOS package is ad-hoc signed and not notarized. This task did not build/test Intel macOS or Windows, create a tag, push commits, or publish a GitHub Release.
