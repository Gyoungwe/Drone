# Drone v0.33.4

This patch makes the skill source identity explicit in the installed desktop
client. The Skills & Connections page now shows repository-level cards for the
bundled Nature Skills and Scientific Agent Skills packs, the optional Academic
Research Skills catalog, pinned commits, bundled/loaded counts, and direct
GitHub links. Individual skills retain their exact repository path and commit;
unmapped local skills continue to show their loader source.

The packaged client checks for research-skill updates after startup and every
two hours. A GitHub API 403/429 rate-limit response falls back to the public
commit Atom feed. Applying a verified archive remains an explicit action and a
guarded restart; a failed check never replaces the active pack.

The macOS arm64/x64 unsigned artifacts were rebuilt and installed locally. ZIP
and DMG payloads, Electron framework symlinks, bounded startup probes, and the
packaged desktop smoke check passed. Evidence is in
[`v0.33.4-asset-validation.json`](v0.33.4-asset-validation.json).

The packaged Skills & connections page now has a first-class Market tab beside
Connectors, MCP and Skills. It shows the Pi extension catalog, Drone registry
metadata (including version and description before installation), official and
community MCP/Skill repository links, localized connector descriptions, and a
sticky section navigator. The real-package P4 acceptance is recorded in
[`v0.33.4-p4-ui-acceptance.json`](v0.33.4-p4-ui-acceptance.json).

Windows and signing remain outside this release's gate. B8 cloud collaboration
and Protocols.io writes remain paused/read-only according to the plan.
