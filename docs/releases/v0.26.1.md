# v0.26.1

Drone 0.26.1 brings the knowledge workspace and the surrounding client language
closer to a calm, reviewable scientific workstation.

## Highlights

- Applied a white, low-noise research visual system to the knowledge home,
  maintenance panel, WebDAV sync area, graph canvas, toolbar, legend and node
  details. Focus states, borders, spacing and shadows now share semantic
  tokens and remain available in both light and dark themes.
- Replaced user-facing internal process vocabulary with plain research
  language. Task plans, system checks, public activity records, source links,
  reproducibility details and knowledge-base actions are easier to understand
  without changing IPC names, persisted data, protocol fields or test hooks.
- Made graph labels bilingual and descriptive: relation density, concept
  depth, outgoing/incoming links and category names now read naturally in the
  selected interface language.
- Includes the PR #113 knowledge observatory and explicit WebDAV sync workbench
  integration, with conflict comparison and deliberate upload/download
  actions preserved.

## Validation
