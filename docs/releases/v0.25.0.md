# v0.25.0

WebDAV 云端知识库、Basic / Digest 认证协商、设置页手动输入密码，以及类型检查和 lint 修复。

## 变更

- 云端知识库（WebDAV）：设置 → 知识库新增 WebDAV 卡片，可显式检查连接、初始化 `Drone-Knowledge` 目录。后端提供单篇读写和显式拉取/推送：更新时用强 ETag 防止覆盖，不自动同步，同名内容不同按冲突返回，删除不会传播（#101）。
- 认证：兼容 Basic 和 Digest。首个请求不再先发 Basic，按服务端的 `WWW-Authenticate` 决定；两者都支持时优先 Digest，只在服务端要求 Basic 时才发送并复用（#101、#104）。
- 密码：可在设置页手动输入、保存和清除，存本机 `knowledge-webdav.json`（权限 0600）。环境变量 `DRONE_WEBDAV_PASSWORD` 优先于保存的密码。界面、日志和 IPC 返回值都不含密码，只标明来源是环境变量还是界面保存。保存或清除不联网，需再点“检查连接”验证（#104）。
- 默认地址仍是 `http://10.126.126.1:8080`，可用 `DRONE_WEBDAV_ENDPOINT` 覆盖。HTTP 下凭据和笔记不加密，界面会提示仅在可信网络使用。
- 测试夹具、模拟用户测试计划与执行报告、云端知识研究升级提案入库（#98、#99、#102、#103）。

## 验证

- `biome check .` 无错误。`npm run typecheck` 通过：此前只在第一个出错的包就停，桌面端云端状态标签的两个类型错误和 antigravity 的 `Headers.entries` 报错都已修复。
- 新增 Basic 复用、Digest 优先、保存密码、环境变量优先、非法密码的测试。
