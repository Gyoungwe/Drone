# Drone v0.7.1

Patch release after Linux desktop regression on v0.7.0. Focuses on permission approvals, UI plugin persistence, Knowledge/Vault reliability, and Linux install docs.

## Fixes

- **Default permission mode** now asks before `edit` / `write` tool calls, so the visual approval dock appears for workspace writes (Fully access still auto-allows with audit).
- **UI plugins** (e.g. whale-maid / voice-alerts): enabling a plugin now persists into `ui-plugins.json` `plugins` (deep-merge); builtin enable is one-click; invalid names fail loudly.
- **Knowledge / Obsidian Vault** submit no longer sticks on 「提交中…」 when a follow-up ask arrives mid-submit (AskGate deferred resolve + AskDialog reset / cancel / timeout).
- **Knowledge chat** host-side tool budget bounds read/search loops (`tool-loop` when exhausted).
- Main log no longer floods on `write EPIPE` / `EIO`.
- Empty-model composer shows a clear CTA to open Settings → Models.

## Docs / UX

- Scout: natural language can start Scout; UI shows 「子代理 x1」 / 「Scout 已完成」.
- Linux install: AppImage may need fuse2 **or** `APPIMAGE_EXTRACT_AND_RUN=1`; `.deb` needs `libsecret-1-0`.
- DeepSeek catalog model names (e.g. **V4 Flash**) vs legacy `deepseek-chat` naming called out in README.
