# Drone v0.16.1

本版本完成 B8 之外的后续架构收尾；B8 团队协作能力暂不实施。

## 架构与运行时

- `SessionService` 进一步拆分为显式 `SessionHost` 组合根，以及 API、设置/诊断、会话构造、控制、事件、消息、模型、资源、权限设置边界和扩展服务；兼容入口保持可用。
- 既有 R5 架构基线全部迁移到 typed package 或正式扩展适配层，架构检查基线清零。
- Obsidian、source archive、Zotero 等扩展使用正式 TypeScript 源入口和可校验生成产物；扩展构建清单不再保留 legacy outputs。
- 知识 specialist host 通过显式版本化宿主事件在不同运行时图之间完成注册与注销，避免模块副本导致的静默失联。

## 研究包与计算验收

- 研究技能包下载按 source/commit/archive SHA 固定缓存，支持原子恢复、离线检查、损坏缓存拒绝和 receipt 校验；release packaging 会执行真实资源校验。
- Docker 单节点 Slurm fixture 修复权限、进程跟踪和 CPU 配置，runner 与 Slurm smoke 可在本地复现。

## 验证

- `npm run lint -- --error-on-warnings`
- `npm run typecheck`
- `npm test`
- `npm run build`
- 架构、插件 API、扩展和 knowledge/tasks/research runtime 检查
- upgrade fixture、research release gate、compute runner 与 Docker/Slurm fixture

真实 Windows、OTP 跳板机和外部 Slurm smoke 仍需要对应 SSH Host 别名、凭据和集群环境；B8 暂不实施。
