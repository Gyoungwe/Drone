# v0.24.0

知识网络图重设计、知识检索回链、任务对账修复、本机 Chrome 预设与 Cloudflare 人工确认、失败熔断调整。

## 变更

- 知识网络：首页直接展示网络图。语义视图过滤基础设施笔记，并合并 `Library/Papers` 与 `Projects/*/Papers` 中标识相同的论文镜像；全部文件视图保留基础设施节点。重复提示不计入度数和社区。可切换聚焦、星云（需 WebGL）和浏览模式，并显示孤立节点与重复数量。点击节点只选中；右侧卡片展示邻居、出链、反链、跳数和警告，只有「打开笔记」会跳转。旧的 `nodes` / `edges` 与 IPC 仍然可用（#96）。
- 知识检索：`research_read_knowledge` 的第一段同时返回出链和反链，各最多 12 条，且只保留仍存在的笔记。`research_search_knowledge` 去掉排序用的内部分数，片段超过 700 字时截断（#92）。
- 任务对账：并行 `set_status` 抬高 `book.revision` 时，`task_reconcile` 不再因此抛出 `stale-task-view`（#92）。
- 浏览器预设改为调用本机 Chrome（`--browser chrome`）。登录态留在浏览器自己的配置里；遇到人机验证时由用户手动完成，程序不绕过验证（#92）。
- 下载或浏览器工具返回 Cloudflare 验证页时，宿主询问一次。继续会对该 URL 重试一次（归档）或要求重新读取页面（浏览器工具）；跳过或关闭卡片记为需要浏览器 / 错误，不算证据。普通 403、登录页和机构认证仍走原来的状态，仅有 `cf-ray` 不会触发询问（#93）。
- 除原生 Windows（`win32`）外，会话不再向模型暴露 `powershell` 工具（#93）。
- 失败熔断：同一失败特征在任务账本里累计 3 次后，拦截下一次调用。计数仍从已有账本推导，不另建状态；修正参数后的恢复路径保持不变（#94）。
- 任务路由过程看板目前只有设计说明、静态草图和结构检查，尚未进入桌面界面，也不改变任务状态机（#95）。

## 验证

- 发布校验此前停在 lint：知识网络图的可选链会在节点列表缺失时调用 `.some`，同文件还有格式问题。这两处已修好。`research-loop` 的来源清单判断、环境注册表归一化，以及测试里未使用的 `claimBinding`，也按现有语义改到 lint 通过。
- 本地已通过 lint、typecheck、`npm test`（先执行 `stage:pi-packages`）和 `npm run test:upgrade`。
