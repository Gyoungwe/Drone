# Drone v0.32.0

继续完善研究工作台界面，统一首页、侧栏、设置和消息卡，并改善知识网络的重复加载与拖动响应。

## 研究工作台

- 首页提供「研究、知识库、接力」三张入口卡，配有插画和衬线标题；知识库、Zotero、远程计算主机的首次配置入口并入卡片（#182、#185）。
- 展开侧栏宽度调整为 180px；浅色界面使用浮起的主内容卡，统一颜色、圆角、字体和基础控件（#170–#174、#183）。
- 输入框保留「模型 · 模式 · 强度」按钮，菜单分为运行配置和权限，悬停显示说明；完全访问开启时常驻琥珀色警示图标（#178、#184）。
- 右栏按「总览、文件、变更、主机」组织；子智能体信息归入总览，变更优先展示文件差异，运行详情可展开查看（#188）。

## 消息、设置与动效

- 助手消息显示模型标识和步骤摘要；交付卡使用衬线标题、类型提示与打开按钮，图片交付带缩略图；错误卡保留继续、重试、设置和复制详情入口（#176、#189）。
- 设置左栏按身份、能力、资源和通用分组，内容区显示分类标题与说明；扩展卸载提供名称、影响说明和明确的危险操作确认（#187）。
- 统一页面和消息淡入、滚动边缘渐隐及运行中文字微光；尊重系统减少动态效果设置（#181、#186）。

## 运行与知识网络

- 主从模式的子智能体并发上限为 1，集群模式为 4；模型可保存可撤销的反馈与用户记忆，设置中展示记忆流转说明（#173、#175、#179）。
- 上下文整理显示提示，继续操作携带工具级续跑上下文（#177、#180）。
- 知识网络按索引修订号复用图快照，索引变化后失效重算，减少重复扫描和布局计算；SVG 拖动按动画帧合并更新，修正缩放后的平移距离（#190）。本次仍沿用现有索引刷新机制，未引入持续运行的力导向动画。

## 发布验证

- Windows 与 macOS CI 覆盖静态检查、后端单元测试、SDK 测试，以及桌面和工作区测试（#169）。
- 发布工作流会在校验通过后创建版本标签，构建 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包，检查安装包及更新元数据齐全后再发布。
