# Drone v0.19.0

本版本把 harness 单元开关、产物卡、决策账本和后台审稿串成一条可追溯的研究状态链，并修复发布包在依赖源码变更后仍可通过校验的问题。

## 主要变化

- **Harness 单元开关**：`harness.context`、`harness.recall`、`harness.guard`、`harness.delivery`、`harness.familyPrompt` 可分别启用；`DRONE_HARNESS_DISABLE` 和兼容总开关继续有效。关闭 `harness.delivery` 时不会触发里程碑后台审稿。
- **产物卡与异步重跑**：产物记录携带来源、运行和会话 provenance；失败计算可进入 durable pending rerun 队列，异步重跑结果回写原产物链。
- **决策账本与撤销**：DecisionRecord 支持项目级记录、人工确认和撤销；撤销会让下游产物进入 `pending-review`，发布在 `artifact-pending-review` 下 fail closed。
- **后台审稿人**：交付里程碑完成后调度 reviewer，审稿警告与不可复现警告可以并存；警告只提示，不削弱 pending-review 的阻断规则。
- **发布产物过期修复**：extensions、knowledge、tasks、research runtime manifest 记录全部 esbuild 输入的组合哈希。传递依赖变化而未重新生成时，各 runtime check 会失败，并有回归测试覆盖 v0.18.0 knowledge 包曾携带旧 Wiki 自动应用逻辑的问题。
