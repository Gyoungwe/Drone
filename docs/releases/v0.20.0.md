# v0.20.0

面向生信科研的工作台能力：知识成网、每日发现、执行位置判断、公共数据库检索、结果查看与标注、Methods 段。

## 新功能

- **知识网络**：笔记查看器显示反链 / 出链；知识库主页「知识网络」图；沉淀知识时自动链接最相关的已有笔记；裸 `[[名称]]` 按唯一文件名解析。
- **每日发现**：默认开，每天一次。基于最近更新的笔记和相关旧笔记，提出最多 3 条有依据、可检验的想法，用户保存或忽略。模型不可用或调用失败时不计入当天，下个整点重试，并在主页显示原因。
- **执行位置**：`/run-on local | <主机> | auto`，选择随会话保存。auto 时 Agent 先用 `bio_environment` 探测本地与已登记主机（远程每次连接需审批），再决定在哪里跑并说明理由。
- **大文件保护**：`read` 整读超过 4 MiB 的 FASTQ / BAM / VCF / FASTA / GFF / h5ad 时被拦截，返回对应的预览命令。
- **dataset 笔记**：参考基因组、注释、数据库的版本、来源 URL、下载日期与校验和，存到 `Library/Datasets`。
- **`bio_db`**：NCBI E-utilities（pubmed、gene、nuccore、protein、sra、assembly、taxonomy、bioproject、biosample）、GEO、UniProtKB、Ensembl、ENA/SRA 的只读检索；结果附检索 URL。
- **结果查看器**：
  - Newick 树：按侧栏宽度自适应，可显示支持度和标尺。
  - 多序列比对：分窗查看、残基着色、保守度行；比对 FASTA 自动识别。
  - HTML 图交互模式：`drone-html://` 协议只服务所选文件所在目录，响应 CSP 禁止网络，iframe 为 `sandbox="allow-scripts"`、无同源。
- **图标注**：在图片或 HTML 图上点击落点写说明，标注按文件保存；「发送给 Agent」把标注整理成修改请求插入输入框。
- **Methods 段**：`research_methods` 从运行记录取事实，起草后弹窗确认，用户同意才写 `<run>/METHODS.md`；文件头注明版本来自声明、未经独立验证。

## 修复

- 工具版本号保留字母后缀（如 STAR `2.7.11b`、bwa `0.7.17-r1188`）。
- 知识网络在索引完成后会刷新。

## 验证

- lint、typecheck、单元与工作区测试、build、`check:arch` 与全部 `check:*`、`test:arch`、`test:upgrade` 均通过。
- 在真实 Electron 中实测：结果查看器各格式、标注全流程、交互 HTML 的沙箱边界（禁网、父页隔离、外部导航拦截）、知识网络与反链、本地 / 远程环境探测脚本、每日发现失败处理。
- `bio_db` 的真实端点检索与远程 SSH 主机探测未在开发环境实测（网络限制 / 无主机），解析逻辑由单元测试覆盖。
