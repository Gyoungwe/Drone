# v0.26.2

Drone 0.26.2 publishes the OpenScience/Wisp-inspired research architecture
upgrade and the generated knowledge runtime required to ship it.

## Highlights

- Adds versioned research contracts, adapter discovery, capability proposals,
  scoped authorization, evidence capsules and replay-safe provenance.
- Connects checkpoint branches, artifact freezing, evidence export and replay
  views through the Electron IPC and desktop UI.
- Adds reusable knowledge snapshots and unknown-assay discovery so an agent can
  research, validate and recommend a workflow without a built-in adapter.
- Regenerates the bundled knowledge runtime so the shipped desktop package
  matches the source tree.

## Validation

The release workflow runs the repository lint, typecheck, architecture,
packaging, runtime, unit-test and production-build gates on Windows before
building and publishing the macOS and Windows artifacts.
