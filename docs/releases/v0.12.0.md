# Drone v0.12.0

本次版本把“一次授权跑完”和“机构合法通道”两件事做到底：示例任务真正一次授权跑到交付，闭源文献通过你自己的机构账号一次登录后自动下载（模板自动保存，无需手动设置），并全面梳理了项目架构与 README。

## 一次授权跑完六大方向任务

- 真实 SDK 模拟六个示例任务（含 Zotero 分支共 7 场景）：之前授权后仍需 2-7 次“推进剩余事项/继续”弹窗、5 次 human_review 确认、每次 Zotero 写入确认，且跑过命令的任务永远停在“部分完成”。现已修复：
  - 模型提前结束但有新进度时，宿主在同授权下自动续作（`reserveHandoff`，需新进度、无等待用户、无 unknown 操作，最多 16 次，reason `automatic-handoff`），不再弹窗
  - 阶段检查不再被并行批次中仍运行的兄弟调用误判为“阶段步数用完”
  - 任务完成不再要求每条 effect 都独立核对，命令类 `returned` 永久问题解决，剩余说明会注明“其中 n 步只有返回记录”
  - DOI 为空的 `zotero_item` 里程碑改为一次写入槽位，授权卡覆盖，写入时不再单独询问（`consent → { slot: true }`，并行批次 claim 表）
  - 五个 `human_review` 示例里程碑改为交付文件（`scope.md`/`interpretation.md`/`revision-notes.md`/`delivery-check.md`/`handoff-check.md`），提示词要求授权后自主完成全部里程碑
- 验收：`example-tasks-one-authorization-sdk.test.mjs` 断言 7 场景均为恰好一次授权卡、0 权限确认、0 面板操作、0 nudges、全部 `completed`。见 `docs/example-tasks.md`、`docs/task-authorization.md`。

## 合法开放获取全文链路

- `research_archive_source` 现在可仅凭 DOI（或 PMCID/PMID）归档：宿主按信任顺序尝试 Europe PMC（身份+OA 标识）、PMC Article Datasets S3（`pmc-oa-opendata`，官方替代已下线的 `oa.fcgi`，含 license 与 `pdf_url`）、Europe PMC render、Unpaywall（`DRONE_CONTACT_EMAIL`）、OpenAlex、Semantic Scholar、Crossref，仅保留真实 PDF 字节，记录查询来源。
- 给定 URL 失败（HTML 落地页、404、登录墙）且 DOI 已知时回退到同一解析。
- 无合法版本时返回 `no_open_access`，带查询来源、publisher handoff 与手动导入路径（浏览器下载 → `.pi/browser-downloads` → `local_file` + `human_verified=true`），绝不走 Sci-Hub 等盗版源。见 `.pi/lib/open-access.mjs`。

## 机构访问（一次登录，自动保存模板）

- **一次登录，自动保存模板，无需手动设置**：Agent 遇到付费墙 → `research_archive_source` 返回 `institutional_auth_required` → Agent 自动调 `research_institutional_login` 打开持久分区 `persist:drone-institutional` 的机构浏览器窗口 → 你完成学校/图书馆登录（EZproxy / Shibboleth / CARSI / OpenAthens / WebVPN）→ 系统监听 `did-navigate`，若 URL 如 `https://ezproxy.xxx.edu/login?url=https://www.nature.com/...` 自动提取为 `https://ezproxy.xxx.edu/login?url=%s` 并保存到 `~/.pi/agent/institutional.json`，下次无需再登录
- **自动下载**：任务授权后逐篇按需、每任务上限默认 20（1-100 可调），仅在过期/验证码时再弹窗口
- **工具**：`research_institutional_login`（打开窗口+自动保存模板）、`research_institutional_status`（只读状态）
- **UI**：设置 → 文献库 → 机构访问，显示登录态、Cookie 数、自动保存的模板，一键登录（自动保存）、刷新、清除、测试访问（输入任意 DOI URL 经会话/模板尝试）
- **合规**：仅用你自己的机构 Cookie，不内置账号，绝不走盗版源，每任务上限防滥用，分区隔离。见 `docs/institutional-access.md`。

## 能力路由与 Zotero 绑定改进

- 能力路由在已批准任务中不再重置：任务进行时任何消息都会恢复 checkpoint 且仅追加新检测的能力；对宿主提示的短回复（启动了/装好了/好的/ok…）也算作续作，无需额外 `capability_load`
- `zotero_item` 里程碑无需在计划时填 DOI：`research_zotero_save` 成功收据（saved/reused，宿主回读 key）会绑定到首个 DOI 为空的里程碑（`milestone.bound`，原合同与哈希不变），下次 reconcile 时回读核对；DOI 为空时显示 pending 而非 blocked。新增 `identify(event, details)` 钩子（`docs/extension-hooks.md` hook 2）
- 当计划或已绑定 DOI 有误时，`task_wait kind=rebind`（`milestoneId` + `doi` + `reason`）打开同一确认卡展示 old→new DOI，用户同意后重绑定，重绑定批准的 DOI 计入计划内 DOI 用于 Zotero 写入授权
