# Drone v0.32.2

本版本完成科研资料捕获与科研连接器控制闭环，并修复来源新鲜度续期问题。

## 科研资料与连接器

- 科研资料页支持逐项启用或关闭研究连接器。
- 连接器开关状态通过 backend 的 JsonStore 持久化。
- 关闭的连接器不会发起搜索请求，并以 fail-closed 方式返回禁用原因。
- 支持 Crossref、PubMed、Europe PMC、Zenodo、OSF、NCBI SRA、OpenAlex、DOI 和 ENA 的只读检索。
- 同一文件的过期来源回执可以重新捕获并生成新的 revision。

## 验证

- PR #208 的 macOS/Windows 8 项 CI 全部通过。
- 正式签名安装包、自动更新和回滚仍需在配置授权证书与 notarization secrets 的 runner 上完成。
