# Drone v0.31.1

v0.31.0 的 UI 遗留项修复。

## 改进

- **模式切换提示常驻**：切换 单体/主从/集群 后，「已切换到 X · 工具变化会重置提示缓存」常驻在输入框底栏，可点 ✕ 关闭，下次发送后自动清除（悬停可看增删的工具）。（#164）
- **思考计时**：时间线思考行与进行中的组标题实时显示「思考中 Ns」，首个正文或工具出现时冻结为「深度思考 X.Xs」。（#165）
- **旧会话步骤时长**：历史会话中的工具步骤时长由持久化时间推导（助手消息落盘时刻 → 工具结果时刻）；无法推导时不显示，也不留空位。（#166）
- **4px 间距网格**：全局间距统一到 4px 网格并引入 `--space-N` 间距 token，修正 6/10/14px 等半步间距；新增守卫测试防回退。（#167）

## 说明

- 旧会话没有持久化思考时间，因此历史思考行不显示时长。
- 若工具声明为顺序执行，历史推导的后续工具时长会包含排队等待时间。
