# Drone v0.13.0

本版本完成 architecture v2 的运行时边界收敛，并把后端会话资源、领域包测试与发布门禁接入同一套可验证流程。

## 架构与后端

- 新增 `SessionPermissionService`，集中承载会话权限模式、快照与清理。
- 新增 `SessionLifecycleService`，承载会话枚举、关闭顺序及资源释放；`SessionService` 保留与项目资源、扩展和文件系统强耦合的创建、打开、删除流程。
- `PiBackend` 保持兼容导出，生产路径继续通过 `BackendServices` 使用拆分后的服务。
- channel-watch 测试支持注入 debounce 窗口；backend unit 测试约 24 秒，unit + SDK 约 33 秒。

## 领域包与架构门禁

- 可迁移的 backend 测试改用 `@drone/knowledge` 与 `@drone/research` 包入口。
- 架构基线从 120 条降至 106 条，剩余项明确属于 host/compatibility adapter 边界。
- CI 纳入 knowledge、tasks、research 三个领域包的测试与运行时产物校验。

## 发布与验证

- CI 增加离线研究技能包发布门禁；release 流程在获取 pinned skill packs 后执行真实 packaging check。
- 全量测试通过：backend 1378 passed + 13 skipped、desktop 556、extensions 16、knowledge 58、research 50、shared 130、tasks 49。
- lint、workspace typecheck、`.pi` checkJs、production build、架构检查、插件/扩展检查与升级 fixture 均通过。

研究技能包按其来源许可和发布流程获取；Academic pack 仅在 release 工作流中以明确的非商业许可依据打包。
