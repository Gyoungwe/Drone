# Drone v0.11.0

本次版本把「上手」「权限」「委派」三件事搬进了界面：六个开箱即用的示例任务、可视化的权限规则编辑页、会话内的子智能体面板与输入框 `@` 派发；同时修正了发布包中学术研究技能包的许可依据。

## 示例任务

- 六个方向各一个内置示例：规划 → 假设、证据 → 文献与证据卡、分析 → 数据质量与检验、写作 → 一节正文 + 审阅、展示 → 图表与幻灯片、工程 → 资源清单与交接。空「任务」页签以卡片展示，`/` 菜单每个方向末尾多一行「示例：…」。
- 小表单收集输入（必填项、原生文件 / 目录选择器、只读的里程碑预览与将要出现的确认），然后发出**一条普通首条消息**（`/skill:…` + 目标 + 输入 + 带编号里程碑的 `task_plan` 请求 + 阶段边界），与输入框走同一条路径。示例不会预建任务、不写文件、不执行任何东西；`task_plan` 与授权卡仍是唯一入口。数据在 `packages/shared/src/example-tasks.json`，新增方法见 `docs/example-tasks.md`。

## 权限设置页

- 设置里新增「权限」页，可视化编辑全局 `~/.pi/agent/permissions.json`：工作区边界（工作区外读 / 写、系统临时区、项目内自动批准）、按工具的规则——其中 `bash` 模式表是有序列表（上移 / 下移 / 添加 / 删除，求值顺序 = 列表顺序，后匹配者生效）、针对未保存草稿的试算（显示某条命令会命中哪条模式）、最近 20 条审计、恢复默认、打开文件位置。
- 四条自保护模式（`*permissions.json*` / `*workspaces.json*` / `*auth.json*` / `*trust.json*`）钉在表尾，不能放宽或删除；后端保存时重新校验（动作合法、无数字键、自保护存在且未被覆盖），文件在页面外被改过时拒绝覆盖（除非明确要求），原子写入（`tmp` + rename，保留 `.bak`），从不改 `enabled`。保存的规则从下一次工具调用起生效。`parseConfig` 现在读取显式的 `autoApproveProjectEdits` 布尔值（推导仍作回退）。见 `docs/permissions-settings.md`。

## 子智能体面板与输入框 `@` 派发

- 上下文面板新增「子智能体」页签：列出当前会话可用的子智能体（内置 `scout`、用户 `~/.pi/agent/agents`、项目 `.pi/agents`——未信任项目的定义可见但不可派发），最多 8 个任务直接派发到本会话（必需工具限定在该 agent 的工具集内、可选阶段契约、工作目录、项目级定义的逐次信任勾选、followUp 默认开），并跟踪本会话的每一次运行：排队中 / 运行中 / 需要回复 / 等待审批 / 完成（待 / 已进入上下文）/ 失败 / 已中止，支持取消、中止、引导、回复、引用、回放与再次派发。
- 派发与模型自己调用 `subagent` 工具走同一条 `runSubagent` 路径（权限门控、互斥、`required_tools`、运行槽），超过 `maxConcurrentSubagents` 的排队与审批行为与以前完全一致；审批坞现在显示请求来自哪个子智能体，并可跳到该运行。完成的运行以 followUp 摘要交给主模型（主模型忙时排队，被消费后卡片翻为「已进入上下文」）；关闭 followUp 时留为结果卡，可引用到输入框。
- 子智能体有了形象：按名称哈希定色的无人机头像 + 来源角标，表情随运行状态变化（纯 CSS，减弱动态时静止）。
- 输入框：在消息开头键入 `@`，先列子智能体再列项目文件；选中后成为胶囊，其后正文即任务，Enter 直接派发到本会话（等价于面板的单任务派发，不经主模型）。`@` 不在开头、处于 `/` 命令内、草稿或只读会话、已有胶囊时行为与以前一致（只补全文件）；胶囊在场时不弹 `/` 菜单；Esc / 空文本 Backspace / × 撤销回 `@name `；派发被拒时整份回填草稿并在错误条显示原因；项目级定义仍需逐次勾选信任，选中后转到面板表单并预选。见 `docs/subagents-panel.md`。

## 发布与许可

- 发布包内含 Academic Research Skills 技能包，依据其 CC BY-NC 4.0 的非商业授权分发：Release workflow 打包前获取三个锁定版本的技能包并为 ARS 记录 `licenseAuthorization: noncommercial`，发布预检接受这一依据。Drone 免费用于非商业用途；接收者受同样的 ARS 条款约束（README 声明、`docs/research-skill-packs.md`）。
