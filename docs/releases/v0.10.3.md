# Drone v0.10.3

本次更新调整任务创建与授权流程：普通聊天不再自动增加任务，授权使用原生弹窗，任务进度集中在侧栏。

## 任务创建与恢复

- 只有模型明确调用 `task_plan` 才会创建任务，补充路径、纠正要求和普通聊天不再各自生成任务。
- 已有任务尚未规划时，为它补充计划；已有不可变计划时，再次提出有效的新计划会创建独立任务，原任务保留为可恢复的 partial 状态。
- `task_plan` 必须提供明确目标；计划先校验再切换任务，无效计划不会留下空任务。
- 新任务不继承原任务的授权或调用预算，原任务的计划、预算、授权记录和会话绑定得到保留。

## 授权与进度

- `task_plan` 和授权类 `task_wait` 直接打开原生授权弹窗，任务状态集中在侧栏。
- 桌面端和 LAN 端聊天正文不再显示任务状态卡；会话数据仍保留状态记录。
- 已授权任务在交付未完成时停下，会询问后续处理方式；剩余事项、原因和下一步使用更清晰的文字。
- 取消、过期版本和变化后的任务绑定不会授予权限，原有工具权限检查继续生效。

## 验证

- 本地后端、桌面和共享模块共 1568 项测试通过，类型检查通过。
- 新增生产工具路径回归，覆盖连续两个 `task_plan`、原任务恢复、预算耗尽和无效计划。
- 日志轮转测试改为等待实际落盘，消除固定等待时间在慢磁盘上的不稳定断言。
- 发布流程在 Windows 和 Linux 上执行检查，并远端构建各平台安装包。

## 安装包

提供 Windows x64、macOS Apple Silicon / Intel，以及 Linux x64 安装包。
