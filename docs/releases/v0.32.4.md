# Drone v0.32.4

本版本将跨平台发布切换为无需证书的 unsigned 模式。

## 发布策略

- macOS 和 Windows 安装包不读取签名证书或 notarization 凭据。
- 发布资产和更新 feed 会上传，并在发布说明中明确标注 unsigned。
- macOS Gatekeeper、Windows SmartScreen 提示以及安装时的人工确认属于预期行为。
- 更新验收覆盖 feed、资产完整性、版本切换和回滚，不宣称系统静默信任。

## 验证

- 版本升级与无证书发布工作流由 PR #213 完成。
- 主线 CI 和发布前完整检查仍按既有跨平台矩阵执行。
