# v0.27.0

Drone 0.27.0 is a desktop UI consistency release: every confirmation,
review and setup surface now shares one accessible interaction layer.

## Highlights

- Unified ActionSurface for Ask, Trust, example tasks and Wiki review:
  dialog semantics on the panel, a top tone bar (accent / warn / danger),
  fit-height cards for short confirmations, a focus trap with focus restore,
  and a reduced-motion-aware entry animation.
- Single dialog stack: only the top surface is visible and interactive;
  Escape closes the top layer only, so overlapping Ask / Trust / example
  dialogs no longer collide.
- Wiki review ignores Escape while a preview or decision is in flight,
  fixing a defer race.
- The first-run guide checks the real knowledge binding, Zotero and compute
  host configuration, hides itself once everything is connected and marks
  configured items.
- Design-system baseline: one global focus ring, global reduced-motion
  fallback, shared empty / loading / error StatePanel, token-based danger
  buttons and accessible toasts.
- Windows: Wiki apply retries the temp-file rename on EPERM/EACCES/EBUSY.
- docs/INDEX.md restored after a corrupted binary write.

## Validation

Interaction tests (jsdom + Testing Library) cover the dialog stack, focus
trap, Escape routing, backdrop clicks, Trust and Wiki review. The release
workflow runs lint, typecheck, architecture, packaging, runtime, unit-test
and production-build gates before publishing artifacts.
