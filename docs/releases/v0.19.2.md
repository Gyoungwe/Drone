# v0.19.2

## 修复

- 局域网远程控制恢复为双闸门行为：`remoteControl` 关闭时没有输入、发送或审批控件；开启后恢复发送和“允许一次/拒绝”。设置页中英文均说明关闭时观察页只读。
- 本地 bash 和 discovery kernel 运行工作区脚本写出交付物时登记 AttemptRecord。记录脚本内容哈希与标量参数、解释器版本摘要、文件哈希及 `runProvenance: local`，不保存脚本或输出正文。本地产物可判定为 `reproducible`/`partial`，不显示重跑按钮。
- 会话替换或重载时任务面板使用稳定的空投影，避免旧会话清理触发 React 最大更新深度错误。

## 验证

- 覆盖 LAN 只读/远程控制、审批、Inquiry 本地 provenance、产物 provenance 展示和面板回归测试。
