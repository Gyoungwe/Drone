# Drone v0.31.0

界面整体改版：降噪、统一字体和卡片规范，对照 ClawsGO 的版式逐页整理。只改界面，没有新增功能，也不改数据格式。

## 运行过程更清爽
- **时间线**（#153）：连续的工具调用合成一行摘要（如「检索 4 篇资料」）；运行中只显示最近 2 步，更早的折叠成「前面 N 步」；阶段说明从卡片改成扁平的圆点加正文。
- **每步耗时**（#162）：工具行末尾显示这一步用了多久（如 5.3s）。旧会话的历史记录没有开始时间，不显示耗时。
- **运行中微光**（#162）：「进行中」标签和当前阶段文字统一用同一条光带动画。

## 输入框
- **模型 / 模式 / 推理强度合并**（#160）：底栏只留一个「模型 · 模式 · 强度」按钮，点开后每一项向右展开选择列表。
- **用量统计收起**（#155）：「会话累计 tokens / 缓存命中」不再常驻在输入框上方，鼠标悬停上下文圆环时显示。
- **模式弹层**（#155）：选中项改为浅灰底加对勾。

## 侧栏和会话
- **带文字的侧栏**（#159）：左侧从 56px 图标栏改为带文字的侧栏，列出「进行中」和「最近」会话，点一下直接打开；右上角按钮可以收起回图标栏。
- **会话两行显示**（#159）：第一行是标题，第二行是「多久前 · 目录」（空间页里第二行是「多久前 · N 条消息」）。

## 右栏、设置、知识库
- **右栏**（#154）：任务运行中、还没有任务清单时，显示运行概览（阶段、工具次数、改动的文件），不再显示示例卡；上下文用量计去掉外框。
- **设置**（#157 #161）：左栏每项有图标、中文名和英文副标，选中改为中性浅灰；弹窗标题放大、留白加大。
- **弹窗按钮**（#161）：主按钮统一为黑色圆角按钮，强调色只用在选中、运行中和链接上。
- **知识库**（#157 #161）：页头、状态卡和内部子卡都去掉了阴影和多余边框。

## 字体、颜色和圆角
- **中文字体**（#158）：字体列表补上 Microsoft YaHei UI、Hiragino Sans GB、Noto Sans CJK SC、Source Han Sans SC，Windows 和 Linux 上的中文显示更清晰；等宽字体统一。
- **字号**（#158）：字号统一为 7 档，最小 11px；正文类文字从 11px 提到 12–13px，设置项也相应放大。
- **圆角和边框**（#156 #158）：圆角统一为 6 / 8 / 12 / 16 / 18px 五档；边框更淡、阴影更柔，不再出现卡片套卡片。
- **强调色**（#156 #157）：深色主题的强调色由紫色改为蓝色（#7c9cff），和浅色主题同一色系；全局强调色只由一个变量控制。
- **数字等宽**（#158）：计数、耗时和 token 数改用等宽数字，数字变化时不跳动。

## 说明
- 改动面较大，主要在 Linux 截图环境里逐页核对过；Windows 真机显示请以实际安装为准，有问题请反馈截图。
