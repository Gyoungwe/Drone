# Drone v0.18.0

本版本把 OpenScience 的上下文管理和 agent harness 思路接入 Drone，重点约束模型如何基于证据工作、如何恢复上下文，以及如何结束一轮任务。

## Agent harness

- 增加模型族、科学合同、回复合同和每轮 effort/delegation/autonomy 姿态；专员使用精简合同，避免挤压隔离 worker 的预算。
- 修复真实 Pi SDK `custom_message`、`custom`、compaction 和 branch summary 的恢复路径，生成有界 checkpoint，并记录合同 fingerprint。
- 增加 `harness_recall` 受控历史导航：只返回有界、可定位的公开片段，过滤私有扩展状态、凭证、查询参数和原始工具日志。
- 增加重复失败重定向、第二次失败阻断、交付物/预算观察，以及 worker attempt、子会话、产物和证据引用追踪。
- 保留现有 task、evidence、knowledge、evaporation 和授权语义；harness 只观察和引导，不接管授权续跑。

## 修复与验证
