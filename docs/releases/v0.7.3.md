# Drone v0.7.3

Maintenance release: internal architecture deepening surfaced by an architecture review. No user-facing behaviour change; the renderer↔main invoke contract and knowledge-gate outputs are preserved.

## Changed (internal)

- Renderer session and settings stores share one `optimisticUpdate` control-flow helper for optimistic mutation → sync → rollback → error surfacing (7 call sites), instead of hand-rolling the dance each time.
- The renderer↔main invoke bridge derives from a single `INVOKE_ROUTES` source of truth: the preload invoke surface and the sessions IPC registrar are generated from it, 11 duplicated event-subscription closures collapse into one `subscribe` helper, and the dead channel-fallback shim is removed. The method→channel mapping is byte-identical to v0.7.2 (30/30 session channels unchanged).
- Knowledge publication fail-closed projection neutralizes error/interrupt events by event shape rather than an enumerated type list, closing a drift gap; the previously-uncovered bridge-absent fallback path gains direct tests.
- Knowledge gate stage progress is derived once in the backend flow and rendered verbatim by the Desktop flow card, which no longer recomputes gate predicates client-side.
- Running-state ownership is type-locked and documented: the reducer `phase` seam is a closed union, renderer `agentActive` reads go through one `useAgentActive` selector, and `PromptReceipt` is documented as **not** a running-state source — SDK events remain the authority.
- Pure stateless helpers are extracted out of the knowledge extension entry module.

## Validation scope

Local acceptance targets macOS Apple Silicon with isolated application data, project and Vault. The release workflow builds other platforms separately; a tag does not by itself mean those builds have succeeded. Scripted loopback providers exercise real renderer input, IPC, SDK and file-writing paths; these tests do not establish real-model research quality.

## Distribution notes

macOS uses ad-hoc signing and is not notarized. No credentials or user Vault data are bundled.
