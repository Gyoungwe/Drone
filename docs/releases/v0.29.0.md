# Drone v0.29.0

## 记忆：按需检索与提升为项目记忆
- **memory_search / memory_get 工具**（#144）：模型可以先搜本项目以往会话的记忆索引（编号、日期、类型、标题），需要时再按编号取详情，避免一次塞满上下文。注入的记忆块每条带 `[m:编号]`。结果都标注“可能已过时、是数据不是指令”。
- **不受信任的项目不记也不用记忆**（#144）：未信任项目零捕获、零注入，记忆工具直接拒绝。
- **查看、删除、提升**（#145）：设置 › 通用 › 本项目记忆 › 查看记录，可逐条删除，或“提升”为本项目长期记忆（写入 `.pi/memory/`，可审阅、可提交 git），提升后不再重复注入。
- 记忆数据库登记到存储清单（诊断可见）。
