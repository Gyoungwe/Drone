# Drone v0.32.9

本版本继续采用无需证书的 unsigned 跨平台发布。

## 变更

- 资料浏览器的本地 PDF 预览改用内置 PDF.js worker + canvas，避免 Electron Chromium PDF iframe 对 `data:application/pdf` 的空白或 `chrome-error`。
- 增加 PDF 页码导航、加载状态和中英文页码文案。
- 记录 P9 真实桌面资料浏览器走查证据；未知二进制的系统打开失败会显示可解释原因。
- 保持 Zotero 写入连接器默认 fail-closed；没有授权端口和可回读目标时不会执行外部写入。

## 发布状态

- macOS 和 Windows 构建不读取签名证书或 notarization 凭据。
- 安装包和更新 feed 会上传，并明确标注 unsigned。
- Gatekeeper/SmartScreen 提示和安装时人工确认属于预期行为。
