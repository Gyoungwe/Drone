# Drone v0.33.2

This patch fixes the packaged knowledge worker seam used by the Knowledge review and graph views. The backend now resolves the generated `knowledge-worker.mjs` from the same `research-workbench/extensions` resource in development and packaged hosts, and fails closed when that resource is missing.

It also fixes the onboarding command profiles and Pi host-version diagnostic, maps failed MCP connections to a red `Unavailable` state with a `View reason` action, and records the offline mainline evaluation contract.

The release remains unsigned and does not add B8 cloud collaboration.

The v0.33.1 arm64 ZIP audit reproduced the reported packaging defect: its
`research-workbench/extensions` tree had no `knowledge-worker.mjs`, so the
updated package check fails closed. The current build includes both the worker
and `.knowledge-worker-manifest.json`; the packaged knowledge smoke passes.
The local unsigned arm64 and x64 application resources both pass the packaged
knowledge check; machine-readable evidence is in
`docs/releases/v0.33.2-knowledge-package.json`.

The first offline mainline evaluation uses 20 fixed questions × 2 rounds:
40/40 local answers, 0 network calls, 40/40 resolvable citations, and a
`1.0` local-answer and citation-resolvable rate. Evidence is recorded in
`docs/evals/mainline-2026-10-19.json`.

Release run [39151148287](https://github.com/Gyoungwe/Drone/actions/runs/39151148287) passed Windows/macOS validation and published the unsigned [v0.33.2 release](https://github.com/Gyoungwe/Drone/releases/tag/v0.33.2) with macOS arm64/x64 and Windows x64 assets.

The public Pi package and host regression evidence is in `docs/releases/v0.33.2-pi-cli-regression.json`; `@gyoungwe/pi-core@0.1.3` and `@gyoungwe/research-suite@0.1.5` are the published patch pair.
