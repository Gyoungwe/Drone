# v0.22.0

能力路由修复、环境复用、知识网络与检索增强、路由路线图、内置 MCP 运行时与语言一致性。

## 变更

- 能力路由修复：`~/.agents` 技能按分组限额，主技能优先并在 `capability_load` 第一行指明先读的 SKILL.md；识别"联配图"等绘图请求；补全 12 类生信路由；"分析＋画图"由分析类做主 skill；新增进化树（phylogeny）阶段，缺工具时给出 mamba 安装命令；里程碑 ID 允许下划线（#79）。
- 环境感知与复用：识别操作系统、架构、shell、WSL 与 GPU；搭好的环境记入 `~/.pi/agent/environments.json`，后续会话复用前先验证；远程服务器只用 SSH key 或 `~/.ssh/config`，每次连接需确认，不存密码（#80）。
- 图增强检索：检索前 3 条结果后沿出链/反链扩展一跳相关笔记作为候选；支持 Obsidian 别名、标题、嵌入等链接写法（#81）。
- 星云知识网络：WebGL（sigma.js）渲染，按主题聚类着色，节点大小反映连接数，支持缩放、平移、悬停高亮，不支持 WebGL 时回退（#82）。
- 路由路线图：每轮路由默认一行显示请求→能力→主技能→阶段→工具→结果，颜色标状态，可展开详情，可切换全文或思维导图视图（#83）。
- 输入框：`/` 指定的 skill 改为行内标签并与正文对齐；放大状态动画改为流内占位，不再遮挡对话（#84）。
- 知识入库标准 I1：知识分类器、frontmatter 模式与标识符规范化（#85）。
- MCP：安装包内置 pi-mcp-adapter 5.1.0（锁定版本），修复浏览器等 MCP 无法加载；路由识别浏览器相关请求；无 MCP 工具时如实告知（#86）。
- 语言一致性：界面语言同步给后端并注入回复语言规则；宿主文案中文模式双语；补齐漏翻的中文词条；Windows 下 shell 输出统一 UTF-8（#87）。
- 知识入库标准 I2：统一项目身份解析（日常空间按会话选项目，其它按工作区），不再默认写入 `research-workbench`，不移动已有文件（#88）。

## 验证

- lint、typecheck、架构检查、扩展构建检查通过；CI（Ubuntu / Windows）全部通过。
