# Drone v0.15.0

本版本完成升级方案的 B5a–B5c 最小可发布闭环，并将新增领域包接入持续集成。

## B5a：可追溯研究状态

- 新增 `@drone/inquiry`，提供 artifact、finding、question、attempt 四类记录、来源谱系、工作区运行记录和清理 dry-run。
- 增加 File、Memory、SQLite 存储实现与 `StorageRegistry`，后端通过 `InquiryService` 统一访问。
- 保留草稿、提升、清理和证据引用的边界，未把宿主或凭据逻辑下沉到领域包。

## B5b：认知发布门禁

- 研究摘要、编号、引用校验和方法工作流纳入发布前检查。
- 诊断漂移、缺失证据和不可引用发现 fail closed；发布结果携带可复核标签。

## B5c：可修复工作流

- 增加先验注册、模块目录、编译/类型检查/预览、失败定位和最多三次修复。
- 重复失败会阻断继续尝试，并记录决策与修复轨迹，避免静默替用户作出不可逆决策。

## 验证

- 全量测试：backend 1408 passed；compute 18；desktop 565；extensions 16；inquiry 6；knowledge 71；research 54；shared 136；tasks 56。
- `npm run lint -- --error-on-warnings`、workspace typecheck、`.pi` checkJs、production build、架构检查、运行时产物检查、插件/扩展检查和升级 fixture 全部通过。
- CI 新增 compute 与 inquiry 测试；knowledge、tasks、research 的测试和运行时产物校验继续保持。

B5d–B5f、B7、B8 以及 PiBackend 进一步拆分、backend 测试耗时优化、剩余架构基线和研究技能包获取依赖保留为后续任务。

研究技能包按其来源许可和发布流程获取；Academic pack 仅在 release 工作流中以明确的非商业许可依据打包。
