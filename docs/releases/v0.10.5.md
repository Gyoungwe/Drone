# Drone v0.10.5

本次版本完成了宿主核心的「去硬编码 / 插件化」重构，并交付了首个受控 Zotero 写入与三栏式桌面壳。

## 通用扩展挂钩

- 工具元数据在 `registerTool(pi, { …, drone })` 里一次声明（只读 / 只读文献模式 / 只读恢复 / 能力路由 / 子代理排除 / 状态条文案 / 回执日志 / 回执卡 / 工具家族），能力路由、只读文献复用、只读恢复、子代理动作描述、状态条和回执日志全部改读这份声明；核心不再维护任何按工具名硬编码的集合与正则。
- 里程碑验收器由扩展登记：`file` / `human_review` 留在核心，`zotero_item` 与 `wiki_review` 分别由 Zotero 与知识库扩展登记；任务授权返回通用的 `acceptances[]`。
- KnowledgeFlow 统一为通用 `cards[]`，归档 / 摄入 / 总结 / 文献回执由同一个 `FlowCards` 组件渲染；桌面新增 `panel.artifacts.card`、`panel.task.milestone-evidence` 槽位与 `panel.tab`、`rail.view` 区域，`DroneUI` 新增 `openExternal`、`useKnowledgeStore`、`i18n.registerMessages`。
- SKILL.md frontmatter 新增 `alwaysWith`，技能可以自行声明在哪些能力激活时常驻可见；第一方与第三方技能走同一条路径。契约说明见 `docs/extension-hooks.md`。
- 修正 `task_plan` 验收 schema：在 `task_plan` 之后加载的扩展登记的验收字段（如 `doi` / `libraryId` / `collection`）现在对模型可见且能通过参数校验。

## 文献与 Zotero

- 新增 `research_zotero_save`：首个由宿主控制的 Zotero 写入。按 DOI 精确去重、已有条目直接复用；除非已授权的任务计划里列出了该 DOI 的 `zotero_item` 里程碑，否则弹出原生同意卡；通过 Zotero 桌面（connector）或带写权限密钥的 Web API 写入一次，并以 DOI 回读判定 `saved` / `unverified` / `failed`。
- 上下文面板「产物」页展示文献回执（DOI、Zotero key 与「在 Zotero 中打开」、Vault 笔记、全文状态），「任务」页在 `zotero_item` 里程碑下展示回读证据；里程碑核对先走桌面本地 API，再走 Web API。

## 桌面壳与交互

- 桌面重排为三栏：42px 标题栏、56px 图标栏（对话 / 项目 / 研究 / 知识）、对话栏，以及 372px 的上下文面板（任务 / 过程 / 变更 / 产物），面板记住开合状态与上次页签。
- 每回合的工具调用、进度与子代理运行折叠为一个 ProcessBlock；回合底部一行 TurnFooter（耗时 · 改动文件 · 费用 · 步数）可直接打开对应面板页签。
- 会话页签支持双击重命名、同名时间后缀与溢出下拉；层级（z-index）与字号统一为固定阶梯。

## 验证

- Windows 与 Linux GitHub Actions：lint、typecheck、全量测试、升级兼容性检查和生产构建均通过。
- 本地全量测试：124 个 backend 测试文件 / 1256 个测试，desktop 460 个测试，shared 93 个测试。
- 对重构前后的行为做了逐项对照审计：旧硬编码名单无遗漏，差异均为扩展作者的显式声明。

## 安装包

Release workflow 将构建 Windows x64、macOS Apple Silicon / Intel，以及 Linux x64 安装包。
