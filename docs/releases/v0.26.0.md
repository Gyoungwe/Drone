# v0.26.0

持久会话与科研知识网络升级。

## 变更

- 知识网络升级为科研观测台：支持主题聚类、健康检查、焦点浏览和研究上下文关联，降低节点过度聚集和文本重叠。
- 会话引擎新增 durable tool intent journal，记录工具意图并在中断后恢复未完成调用。
- 支持部分工具输出检查点，长输出在会话中断后可继续处理而不丢失已接收内容。
- 新增持久 session inbox 与版本化 durable state documents，保证恢复状态可迁移并能审计。
- 外部科研效果支持幂等键，重试研究归档、知识写入等操作时不会重复产生副作用。

## 发布验证

- 主线已按依赖顺序合并持久会话系列 PR #106、#107、#108、#109、#111、#112。
- 知识网络重设计 PR #110 已合并。
