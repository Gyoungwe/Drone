# Drone v0.32.8

本版本继续采用无需证书的 unsigned 跨平台发布。

## 发布状态

- macOS 和 Windows 构建不读取签名证书或 notarization 凭据。
- 安装包和更新 feed 会上传，并明确标注 unsigned。
- Gatekeeper/SmartScreen 提示和安装时人工确认属于预期行为。
- 更新验收覆盖 feed、资产完整性、版本切换和回滚。

## 验证

- unsigned 环境变量现在只在 build job 中声明，并在构建后的校验步骤中复用。
- v0.32.5 skill-pack 校验参数、v0.32.6 触发路径和 v0.32.7 变量作用域问题均已修复。
- 主线 CI 与 Release validate 继续执行完整跨平台检查。
