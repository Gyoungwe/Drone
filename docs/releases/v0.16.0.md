# Drone v0.16.0

本版本完成升级方案 B1–B7（B8 按要求暂不实施）。

## B1–B3：远程计算与 RNA-seq 垂直切片

- `@drone/compute` 提供 direct/Slurm 工作流、状态机、幂等提交、对账、预算与产物清单。
- backend 使用固定 JSON runner；支持本地 direct、SSH/`ssh2`、系统 OpenSSH 回退、known-hosts/指纹校验、SFTP、ProxyJump、keyboard-interactive、终端、取消、断线未知态和 bounded logs。
- runner、Docker/单节点 Slurm fixture、取消/重连/幂等/产物校验测试已加入仓库。
- RNA-seq 固定 nf-core/rnaseq 3.18.0、revision 和容器 digest；接入 provenance、MultiQC/QC gate 与显式真实 smoke 命令。
- Electron extraResources 携带 runner，桌面计算面板和初始化检查接入 ComputeContract。

## B4–B5：研究状态与发现层

- B5a 的 InquiryService 现在接收计算终态与任务终态事件，登记 artifact/attempt 并保持项目隔离、串行写入和只读快照。
- B5d–B5f 新增 `@drone/discovery`：容器门控的 Python/R 内核、探索预算与先验、竞争解释、只读批评者、多路径稳健性和评测/缺数据/阻断结果。
- B4 的 knowledge experience store 与 plan proposal 授权闭环保持可检索、可失效和可追溯。

## B7：数据管理与实验设计

- 数据集按内容寻址登记，样本表和设计矩阵在提交前校验，公共数据记录 URI、许可、条款、时间和 checksum。
- 分析计划提供功效/MDE、偏离复核和设计合同哈希；确定性 RO-Crate 导出数据、流程和 provenance 引用。
