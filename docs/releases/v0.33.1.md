# Drone v0.33.1

这是 v0.33.0 之后的宿主补丁版本，收口公开插件包的安装边界并刷新发布前验证证据。

## 插件宿主

- Desktop/Pi 从 registry 安装并加载 `@gyoungwe/pi-evidence`、`@gyoungwe/pi-connectors` 与 `@gyoungwe/desktop-ui-pack`。
- 宿主不再保留 evidence/connectors 的临时源码副本；公开包版本固定在 lockfile。
- 公开包 tarball、Pi loader、干净安装和 Desktop UI 生命周期均通过验证。

## 验收

- `npm run lint`、`npm run typecheck`、`npm test`、`npm run build`、`npm run check:arch` 通过。
- 剩余门槛、插件 API 生命周期、Pi 1.1.0/latest 兼容矩阵、research-suite、UI/SKILL 与升级 fixture 通过。
- `npm run check:desktop-artifact -- --strict`：16/16，通过四视口 4/4，0 `FAIL`、0 `NOT_RUN`。
- `../drone-plugins` 的 `npm run check` 通过，六个插件 manifest、干净安装和 tarball 检查通过。

## 发布策略

本版本继续使用项目约定的无证书跨平台构建。签名证书不属于发布门槛；系统信任提示属于 unsigned 安装的预期行为。
