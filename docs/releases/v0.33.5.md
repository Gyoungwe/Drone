# v0.33.5 插件门禁收口（无证书）

本轮收口了插件化计划中的 Skill 仓库管理、知识库 worker 失败回滚、原生 Pi/MCP 验收和深色构建渲染对照。Skill 仓库支持 Git URL 或本地目录、分支/路径/许可依据、哈希校验、原子应用、失败保留和来源卸载；worker 在候选健康检查失败时保留当前版本，并在排空后切换。

真实 registry 包 `@gyoungwe/pi-core@0.1.5` 在 Pi `1.1.0` 独立 HOME 中安装，`/drone-doctor` 解析宿主版本并通过，真实模型会话返回 `NATIVE_PI_REGISTRY_OK`，随后卸载。`pi-mcp-adapter@5.1.0` 通过 stdio fixture 完成真实 `mcp__echo` 调用并返回唯一值，卸载后清理。

深色新任务、知识库、技能与连接、主机四视图的 built-renderer headless 对照为 4/4 PASS。交互式 Electron GUI、外部用户自定义 MCP 和官方第三方 extension 未作为通过证据；Pi CLI 的 `update` 命令仍需确认版本替换语义。B8 云端协作保持暂缓，Protocols.io 保持只读，桌面继续采用无证书策略。

完整证据见 [`v0.33.5-plugin-gates.json`](v0.33.5-plugin-gates.json) 和 [`visual/drone-visual-comparison-dark.json`](visual/drone-visual-comparison-dark.json)。
