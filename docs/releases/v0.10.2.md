# Drone v0.10.2

本次更新集中修复任务授权后的自动续作，并让任务进度和剩余事项更清晰。

## 修复

- 修复任务状态消息插入工具调用与结果之间，导致 OpenAI 兼容接口返回 400 的问题；在发送上下文前恢复旧会话中这类已完整记录、但顺序错位的消息，不补造结果或重做操作。
- 任务规划与授权工具保持可见，不再被能力筛选隐藏。
- 同一任务按钮的并发请求在命令入口合并，避免重复点击取消原续作；取消后仍可显式重试。
- 文件输入中的“补充说明”不再视为正式提交；取消、失效上下文或会话关闭不会误启动续作。
- 原有授权入口确认后也会沿用有效任务授权继续推进。

## 任务工作台

- 进度条改为“已验收交付项 / 总交付项”，不再将工具调用预算消耗当作完成率；调用预算独立显示。
- 显示剩余交付项、已知原因和下一步。区分缺少验收记录、约定路径未找到文件、前置事项和必要人工处理，不凭空断言工作尚未完成。
- 侧栏与任务卡提供原生 ask_user 快速推进入口：继续原范围工作、只读核对、补交文件或确认已完成的人工审阅。
- 不自动勾选未验收项，不降低完成标准；新增风险、范围、预算及 Wiki 专用审阅边界仍受保护。

## 验证

- 冻结代码后：后端 1054 项、桌面 433 项、共享模块 72 项，共 1559 项测试通过。
- 类型检查、变更文件代码检查和桌面构建通过。
- 新增真实 SDK + 模拟模型回归：重复点击、取消后重试、文件提交/取消/补充说明、会话关闭与重新打开。
- 未调用付费模型，未操作真实 Zotero 或用户知识库；外部服务自身故障不在上述实测保证范围内。

## 安装包

提供 Windows x64、macOS Apple Silicon / Intel，以及 Linux x64 安装包。
