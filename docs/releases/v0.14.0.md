# Drone v0.14.0

本版本完成 architecture v2 的 B1–B4 阶段集成，新增可验证的远程计算、声明式 RNA-seq 工作流和研究闭环能力。

## 远程计算与工作流

- B1 增加持久化计算作业服务、单调状态协调、固定 runner 协议、产物校验和幂等提交边界。
- B2 增加主机、健康、作业、日志、终端和引导状态的共享契约、IPC/preload 投影及任务级计算授权。
- B3 增加 WorkflowSpec 校验、类型/环检查、Nextflow DSL2 编译、direct/Slurm argv seam、nf-core/rnaseq test profile、MultiQC 门禁和远程 provenance。
- 计算领域包保持宿主无关；真实 SSH/Slurm/Docker 连接仍由后续宿主适配任务接入，当前发布验证使用注入的 fake runner。

## 研究和任务闭环

- B4 增加研究运行摘要、证据门控的 topic memory/Wiki deposit、方案提案与授权卡、经验存储和第三次失败阻断规则。
- B2 的计算范围与 B4 的方案提案同时呈现在授权卡中，批准哈希继续作为不可变执行边界。

## 验证

- 全量测试：backend 1387 passed + 13 skipped；compute 14；desktop 565；extensions 16；knowledge 66；research 54；shared 136；tasks 56。
- `npm run typecheck`、`.pi` checkJs、桌面 production build、架构检查、运行时产物检查、插件/扩展检查和升级 fixture 全部通过。

研究技能包按其来源许可和发布流程获取；Academic pack 仅在 release 工作流中以明确的非商业许可依据打包。
